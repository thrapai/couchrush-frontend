# Cookies

## couchrush_language

- Name: `couchrush_language`
- Purpose: Remembers the selected interface language.
- Values: `en` or `el`
- Duration: 1 year
- Type: First-party functional preference cookie
- Notes: `Path=/`, `SameSite=Lax`, `Secure` in HTTPS environments, not `HttpOnly` because the frontend must read and update it.
